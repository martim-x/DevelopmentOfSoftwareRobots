## 1. Точные задания из методички

- **Задание 8-1.** Процесс, который создаёт скриншот, записывает его в папку с
  уникальным именем (дата/время из `CurrentDateTime`) и открывает в Paint для
  корректировки. Серия снимков по горячей клавише **Ctrl-Q** (ожидание горячей
  клавиши, диалог «Продолжать? (1-да, 0-нет)», «Перейти к» метки Begin).
  Папка под снимки создаётся заранее (методичка, имя проекта **Sreenshot-Pad**).
- **Задание 8-2.** Процесс, извлекающий заголовки **первых двух новостей** с
  сайта **https://yandex.by/news** по задаваемой теме (диалог темы → запуск
  Edge → фокус в поле поиска → отправка темы с Enter → «Получить сведения об
  элементе на веб-странице», атрибут Own Text, ×2 → список → сообщение →
  закрытие браузера).
- **Задание 8-3.** Процесс, добавляющий записи в БД «Зарплата»: скрипт создания
  базы Salary и таблицы Зарплата (9 полей, 5 стартовых сотрудников) приведён в
  методичке дословно; поток — подключение SQL, проверка пустоты (select count),
  очистка по подтверждению, цикл диалогового ввода (ФИО, должность, стаж,
  оклад, премия) с проверкой ConfirmButton='OK' на каждом поле, insert,
  8 update-инструкций расчёта начислений (надбавки 0/5/10/15/20 % по стажу,
  итог, налог 13 %, к получению), select * и построчный вывод сотрудников,
  закрытие подключения.
- **Задание 8-4.** Самостоятельная постановка задачи + процесс. В отчёте
  сформулирована: распознавание числовых значений с изображения
  `ValuesForSum.jpg` и вычисление их суммы.

## 3. Проверка доступности источников (фактические прогоны, 18.11.2026)

- `https://yandex.by/news` — **не открывается с этой машины**: TLS-ошибка
  (certificate verify failed / WRONG_VERSION_NUMBER), т.е. методичечный
  источник задания 8-2 недоступен и через Edge, вероятно, тоже не откроется.
- `https://devby.io/news` (dev.by) — **HTTP 200**, заголовки новостей в
  серверном HTML (`div.card__title`, 30 карточек; примеры: «Salesforce и Intel
  снова увольняют», «Windows 11 тайно следит, какими ИИ-агентами вы
  пользуетесь»). Поиск сайта ведёт на Google CSE (`google.com/cse`) — заголовки
  результатов в iframe, селекторы подбираются в PAD.
- `news.yandex.by`, `news.tut.by`, `lenta.ru`, `kaktusik.info` — блокируются
  сетью (TLS/DNS); `onliner.by` открывается, но поиск — SPA.
- **Предложение (требует согласования контроллером):** заменить источник
  задания 8-2 на devby.io/news — план прямо разрешает «согласованную замену,
  а не придуманные новости».

## 4. Расхождения методичка ↔ план ↔ текущий отчёт (зафиксировать при пересборке)

1. **Листинг 8 отчёта (самостоятельная задача) не соответствует постановке:**
   в нём суммируется `TextList.Count` и лишний Excel-блок от lab7 (OcrList), а
   не сумма значений. В подготовленном `SumOfValues-Pad.robin` сумма значений
   считается верно (12+8+15+5=40). При пересборке отчёта листинг 8 заменить на
   последовательность из SumOfValues-Pad.
2. **Листинг 6 отчёта (БД)** не показывает повторный вопрос «Желаете создать
   ещё одну запись?» внутри цикла (методичка, п. 12) — в `Salary-Pad.robin` он
   есть; отчёт дополнить при пересборке.
3. **Строка подключения** в отчёте содержит чужой сервер `Server=STANISLAW`;
   в исходнике — `localhost` с пометкой заменить на фактический экземпляр.
4. **Задание 8-2:** источник yandex.by/news недоступен (см. §3) — либо
   согласовать замену на devby.io/news, либо подтвердить доступность yandex на
   машине контроллера; отчётный текст о «новостном сайте» останется верным.
5. **Имя проекта Sreenshot-Pad** (опечатка методички) сохранено сознательно —
   как в задании и в текущем отчёте.
6. **Титул отчёта** (Марушко Т. Ф., группа, проверил Сазонова Д. В.) —
