# Разработка программных роботов

Учебный репозиторий по дисциплине «Разработка программных роботов» (ИСиТ, 3 курс, осенний семестр 2026/2027).

## Структура

- `lectures/` — лекции.
- `labs/` — задания лабораторных работ.
- `labN/` — решения и рабочие материалы по конкретным ЛР:
  - `labN.docx` — отчёт по лабораторной работе (сдаваемый документ);
  - `labN.pdf` — PDF-копия для быстрого просмотра и контроля вёрстки;
  - `build/report.json` — исходник отчёта (блоки для сборщика `BstuReportBuilder`),
    отчёты всех восьми лаб собраны из него;
  - `build/скрины/` — иллюстрации отчёта, имена `taskN_описание.png` для лаб 5–8
    и `figNN_описание.png` для лаб 1–4 (имена сохранены от исходных отчётов);
    в лаб 8 иллюстрации опущены, вместо них листинги с кодом в `report.json`;
  - `app/` — проекты автоматизации UiPath (`.xaml`, `project.json`, данные).
- `helper/` — отчёты по лабораторным работам 1–8, предоставленные как образец
  (из них взят текст шагов и скриншоты для лаб 1–4).
- `BACKLOG.md` — реестр технических долгов по лабораторным работам.

## Отчёты

Отчёты собираются сборщиком `BstuReportBuilder` (репозиторий `BstuReportBuilder`)
из `report.json` по правилам СТП 001-2019: поля 23/10/20/15 мм, Times New Roman
14 пт, абзацный отступ 12,5 мм, нумерация страниц в правом верхнем углу,
титульный лист без номера. Сдаваемый документ — `docx`; PDF используется только
для контроля вёрстки.

Пересборка отчёта (Windows, драйвер обходит отсутствие LibreOffice: PDF через
Microsoft Word COM, номера страниц — через PyMuPDF):

```
py -3.13 build_report.py labN/build/report.json labN/labN.docx --check
```

Драйвер `build_report.py` — тонкая обёртка над `BstuReportBuilder`: сборка,
оглавление с номерами страниц и проверки `app.checks` (те же требования СТП,
что и в CLI сборщика).
